# La Canasta

Aplicación web progresiva (PWA) pensada para anotar puntos, gestionar jugadores y parejas, y consultar el reglamento y los valores de las cartas de La Canasta desde el celular.

## Características

- Modos de juego Individual y en Parejas.
- Calculadora de rondas por bloques: bonos de corte, reparto y espejito, tres rojos, canastas puras e impuras, y conteo rápido de cartas en mesa y en mano.
- Cálculo automático del puntaje mínimo para abrirse según el acumulado, con reglas y cantidad de mazos configurables.
- Tabla general comparativa por rondas, gráfico interactivo de evolución y estadísticas históricas por jugador.
- Instalable como app móvil (PWA), con funcionamiento offline y copia de seguridad local.

## Instalación y uso local

```bash
npm install
npm run dev     # servidor de desarrollo
npm run build   # build de producción
```
